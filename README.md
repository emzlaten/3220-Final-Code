# 3220-Final-Code

This project analyzes consumer factors that influence the likelihood of purchasing an electric vehicle (EV). Using a synthetic dataset containing demographic, economic, behavioral, and environmental information, we use multiple analyses and predictive modeling techniques to identify which variables are most strongly associated with EV adoption.



The dataset contains 15 features including age, annual income, commute distance, charging station availability, environmental concern, city type, vehicle ownership information, and government subsidy availability. The target variable is Will\_Buy\_EV, which indicates whether a person is interested in purchasing an electric vehicle.



To run the code, have the train.csv dataset and TeamProject.rmd in the same directory, then knit TeamProject.rmd.
